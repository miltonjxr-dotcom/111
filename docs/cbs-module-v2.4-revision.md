# CBS 模块 v2.4 — 做市商行为穷举 + 指标 6 重新评估

> 版本: v2.4 | 日期: 2026-04-13
> 本版本回应两项反馈：做市商行为穷举 + 指标 6 是否应参与评分的深度重审

---

## 一、做市商行为穷举与信号收纳

### 1.1 做市商的行为维度

做市商的链上行为可以从 5 个维度穷举：**LP/流动性管理、资产转移、交易行为、合约/关系变化、衍生品行为**。

### 1.2 维度 A：LP / 流动性管理行为

| # | 行为 | 描述 | 投研含义 | 价值 |
|---|------|------|---------|:----:|
| A1 | **首次为某 Token 添加 LP** | 在此前从未做过市的 Token 上部署流动性 | 新做市关系建立，可能暗示上所/合作/项目方签约 | ★★★★ |
| A2 | **大幅增加做市深度**（>50%） | 在已做市 Token 上显著加码 | 预期交易量增加/主动看好/收到新的做市合约 | ★★★ |
| A3 | **大幅削减做市深度**（>50%） | 显著减少已做市 Token 的流动性 | 风控/合约到期/预见负面事件/流动性危机预期 | ★★★★★ |
| A4 | **完全撤出做市** | 从某 Token 全部撤出 LP | 最强风险信号——做市商彻底放弃该 Token | ★★★★★ |
| A5 | **收窄做市区间** | 从宽区间调整为窄区间 | 降低方向性暴露，预期高波动或不确定性增加 | ★★★ |
| A6 | **拓宽做市区间** | 从窄区间调整为宽区间 | 增加暴露面，预期波动降低或信心增强 | ★★ |
| A7 | **做市区间整体上移** | 区间中心价上移 | 做市商认为公允价格应该更高 | ★★★★ |
| A8 | **做市区间整体下移** | 区间中心价下移 | 做市商认为公允价格应该更低 | ★★★★ |
| A9 | **跨链部署做市** | 在新链上为同一 Token 首次做市 | 多链扩展信号，可能暗示该 Token 即将在新链生态上线 | ★★★★ |
| A10 | **从链 X 撤出、转移至链 Y 做市** | 将流动性从一条链迁移到另一条链 | 生态迁移信号——资金和用户可能在向新链转移 | ★★★ |
| A11 | **多 Token 同时撤出做市** | 同时减少/撤出多个 Token 的 LP | 做市商级别的系统性风控——可能预见到全局性风险 | ★★★★★ |

### 1.3 维度 B：库存管理与资产转移

| # | 行为 | 描述 | 投研含义 | 价值 |
|---|------|------|---------|:----:|
| B1 | **库存偏向 Token 端** | 做市过程中有意持有更多 Token（而非稳定币） | 隐含看多——愿意承担 Token 方向性风险 | ★★★★ |
| B2 | **库存偏向稳定币端** | 做市过程中有意持有更多稳定币 | 隐含看空/避险——在做市中逐步退出 Token 敞口 | ★★★★ |
| B3 | **从 CEX 提出大量某 Token** | 从交易所提出 Token 到链上 | 可能准备做市（利好）或准备链上操作 | ★★★ |
| B4 | **向 CEX 充入大量某 Token** | 将 Token 从链上转入交易所 | 可能准备在 CEX 做市（中性）或准备出售（偏空） | ★★★ |
| B5 | **跨地址大额转移** | 做市商在自有地址之间转移大额资产 | 内部调仓，通常中性。但如果伴随其他信号可能是减仓准备 | ★★ |
| B6 | **接收项目方大额 Token 转入** | 从项目方/基金会地址接收 Token | 新做市合约启动/Token 解锁分配给做市商 | ★★★★ |
| B7 | **向项目方退回 Token** | 向项目方地址退回 Token | 做市合约结束/关系终止 | ★★★★ |

### 1.4 维度 C：交易行为（非做市范围内）

| # | 行为 | 描述 | 投研含义 | 价值 |
|---|------|------|---------|:----:|
| C1 | **在非做市 Token 上大额买入** | 用非做市地址或在非做市对上方向性买入 | 自营方向性交易，信号极高——做市商有全局信息优势 | ★★★★★ |
| C2 | **在非做市 Token 上大额卖出** | 方向性卖出 | 同上，看空信号 | ★★★★★ |
| C3 | **在做市 Token 上异常单向大额交易** | 在正常做市的 Token 上出现远超常规做市量的单向操作 | 自营交易混入做市——高价值信号但需从做市噪声中分离 | ★★★★ |
| C4 | **做市商间大额 OTC 转账** | 与其他做市商之间的大额对价转移 | 场外大宗交易，可能暗示机构级别的仓位调整 | ★★★ |
| C5 | **在多个 Token 上同方向操作** | 同时买入/卖出多个同板块 Token | 板块性配置/清仓信号——做市商在做板块层面的判断 | ★★★★ |

### 1.5 维度 D：合约/关系变化

| # | 行为 | 描述 | 投研含义 | 价值 |
|---|------|------|---------|:----:|
| D1 | **部署新的做市合约/策略地址** | 在链上创建新的合约地址用于做市 | 新策略上线或新做市关系 | ★★ |
| D2 | **参与治理投票** | 用做市库存中的 Token 参与 DAO 投票 | 做市商对项目治理有看法——通常表明较深度的参与关系 | ★★★ |
| D3 | **多家做市商同时入场某 Token** | 多家独立做市商几乎同时开始做市 | 极强信号——可能有公开/非公开信息表明该 Token 即将有重大事件 | ★★★★★ |
| D4 | **多家做市商同时撤出某 Token** | 多家独立做市商几乎同时撤出 | 最强风险信号——做市商集体风控 | ★★★★★ |

### 1.6 维度 E：衍生品行为

| # | 行为 | 描述 | 投研含义 | 价值 |
|---|------|------|---------|:----:|
| E1 | **在 Hyperliquid/GMX 开多头** | 做市商在 Perp 上建立方向性多头 | 如果同时在现货端做市，说明对 Token 有自营看多判断 | ★★★★ |
| E2 | **在 Perp 上开对冲空头** | 做市商在做市的同时在 Perp 做空 | 对冲行为——做市商不看好方向但仍维持做市义务 | ★★★★ |
| E3 | **Perp 仓位突然大幅变化** | 做市商的衍生品仓位出现异常变动 | 风险管理调整或方向性判断变化 | ★★★ |
| E4 | **做市商反向操作**（做市同时方向性做空） | 在为某 Token 做市的同时通过其他渠道做空 | 利益冲突信号——可能在利用做市优势做空 | ★★★★★ |

### 1.8 Event Layer 做市商处理流程

```
做市商 (C1) 事件处理:

1. 识别行为维度:
   ├── LP/流动性变化 → 维度 A 分析
   ├── 资产转移 → 维度 B 分析
   ├── 交易行为 → 维度 C 分析
   ├── 合约/关系变化 → 维度 D 分析
   └── 衍生品行为 → 维度 E 分析

2. 判定是否含方向性:
   ├── C1/C2/C3/C5 → 含方向性的交易 → 计入指标 1
   ├── B1/B2 → 含隐含方向性的库存偏移 → 指标 6 事件 (附方向性标签)
   ├── A7/A8 → 含隐含方向性的区间移动 → 指标 6 事件 (附方向性标签)
   └── 其他 → 非方向性事件 → 仅计入指标 6

3. 判定严重等级:
   ├── ★★★★★ (A4/A11/D3/D4/C1/C2/E4) → 最高优先级异动推送
   ├── ★★★★ (A1/A3/A7/A8/A9/B1/B2/B6/B7/C3/C5/E1/E2) → 高优先级推送
   └── ★★★ 及以下 → 记录但不推送，仅在 Dashboard 展示
```

## 二、指标 6 是否应该参与评分：深度重审

### 2.1 v2.3 的决策回顾

v2.3 将指标 6 定义为"事件流"，不参与 CBS Score 加权。理由是"指标 6 捕获的买入/卖出事件已经计入指标 1，再参与加权是重复计分"。

### 2.2 这个决策对吗？不完全对。

v2.3 的推理有一个隐含假设：**指标 6 的所有事件都已经被其他指标覆盖了。** 但仔细穷举后发现，事实并非如此。

让我列出指标 6 捕获的所有事件类型，逐一检验"是否已被其他指标覆盖"：

| 事件类型 | 是否已被其他指标覆盖 | 具体分析 |
|---------|:--:|------|
| **大额入所** | **部分覆盖** | 指标 4（交易所流量）记录了金额，但**没有记录是谁**。10 个散户各充 $50K 和 1 个鲸鱼充 $500K 在指标 4 中完全一样（都是 $500K），但投研含义天壤之别。 |
| **大额出所** | **部分覆盖** | 同上。指标 4 记录金额但不记录实体。 |
| **跨链迁移** | **未覆盖** | 指标 1-5、7 都不捕获跨链迁移。跨链不是买卖，也不改变 CEX 入出金，也不改变持仓集中度（资产从链 A 消失、在链 B 出现）。 |
| **冷→热钱包转移** | **未覆盖** | 纯内部转账，不触发任何其他指标。但它经常是卖出的前兆。 |
| **做市商区间上移/下移** | **未覆盖** | 做市商调整区间不产生 Swap 事件，不影响 CEX 流量，不改变持仓占比。 |
| **做市商库存偏移** | **未覆盖** | 是价格变动导致的被动变化 + 主动不调仓的结果，不产生独立事件。 |
| **做市商撤出做市** | **部分覆盖** | 撤出 LP 会体现在指标 7（流动性环境），但指标 7 是全量 LP（不限白名单），做市商撤出可能被其他 LP 加入对冲，导致指标 7 变化不大但实际风险很高。 |
| **多家做市商同时入场/撤出** | **未覆盖** | 这是"模式识别"——需要检测"多个 C1 实体在短时间内做了同方向的事"。其他指标都是单维度数值，无法表达这种跨实体模式。 |
| **做市商自营买卖** | **已覆盖** | 指标 1 已计入确认买入/卖出。 |
| **首次参与** | **部分覆盖** | 指标 3（参与动态）记录了新增实体数，但不记录**是哪个实体**。"新增 3 个实体" vs "新增的是 a16z"——后者的信号含量高 10 倍。 |
| **异常规模操作** | **部分覆盖** | 金额计入指标 1，但"异常"这个特征未被记录。$800K 的买入是正常的还是该实体历史的 16 倍——指标 1 不区分。 |
| **做市商 Perp 行为** | **部分覆盖** | Perp 修正项覆盖了方向性判断，但不覆盖"做市商反向操作"这种利益冲突信号。 |

**统计结果**：

- 完全未被覆盖：4 种（跨链迁移、冷热转移、区间移动/库存偏移、多做市商同向模式）
- 部分覆盖（其他指标记录了金额但没记录"谁"或"是否异常"）：5 种
- 已被覆盖：1 种（自营买卖）

**结论：指标 6 的 12 种事件中，有 9 种提供了其他指标未覆盖的独特信息。v2.3 将其完全排除出评分是错误的。**

### 2.3 但让指标 6 直接参与加权也有问题

指标 6 的根本难点在于：**它不是一个连续数值，而是一个离散事件集合。**

- 指标 1 = "+$2.3M"（连续值，可以直接参与加权）
- 指标 6 = "今天有 3 个事件：Paradigm 入所、Wintermute 撤 LP、a16z 首次参与"（离散值，如何变成一个数字？）

如果强行量化：

| 量化方案 | 问题 |
|---------|------|
| 按事件数量算 | "3 个事件" vs "1 个事件" —— 但 1 个"多家做市商同时撤出"比 3 个小事件重要 100 倍 |
| 按事件严重等级加权 | 可以做，但严重等级的打分标准主观性强，难以回测 |
| 按事件隐含方向性算 | 可以做——每个事件标注隐含方向和强度，加总后得到有向值 |

### 2.4 最终方案：指标 6 拆分为两层

**指标 6 不是一个指标，而是两层输出。**

#### 层 1：方向性事件评分（参与 CBS Score）

将指标 6 事件中**有明确方向性含义的部分**提取出来，量化为有向值。

| 事件 | 方向 | 评分规则 |
|------|:----:|---------|
| 大额入所 | 偏空 | 按 (入所金额 / 该实体总持仓) × 实体质量权重 计入负分 |
| 大额出所 | 偏多 | 按 (出所金额 / 合理估计值) × 实体质量权重 计入正分 |
| 冷→热钱包转移 | 偏空 | 固定负分（前兆信号，置信度不高但方向明确） |
| 做市商区间上移 | 偏多 | 按偏移幅度比例计分 |
| 做市商区间下移 | 偏空 | 按偏移幅度比例计分 |
| 做市商库存偏向 Token | 偏多 | 按偏移程度计分 |
| 做市商库存偏向稳定币 | 偏空 | 按偏移程度计分 |
| 做市商撤出做市 | 偏空 | 按撤出比例 × 做市商评级计入负分 |
| 做市商新增做市 | 偏多 | 按做市商评级计入正分 |
| 多做市商同向入场 | 强偏多 | 高权重正分（罕见且信号极强） |
| 多做市商同向撤出 | 强偏空 | 高权重负分（罕见且信号极强） |

量化方式：

```
指标6_score = Σ (event_direction × event_magnitude × entity_quality)

其中:
- event_direction: +1 (偏多) 或 -1 (偏空)
- event_magnitude: 事件规模的归一化值 (0-1)
- entity_quality: 实体质量评分 (0-1)
```

#### 层 2：事件明细流（不参与评分，服务分析师）

不可量化的部分、以及量化后仍有独立叙事价值的部分，作为事件明细流输出：

- **"谁做了这件事"** —— 实体身份、分类、历史画像
- **"这次是否异常"** —— Contrast Layer 基线对比
- **"跨链去了哪里"** —— 迁移目标链和可能原因
- **"首次参与的是谁"** —— 实体身份（指标 3 只计数不记名）
- **"做市商反向操作"** —— 利益冲突警示（不宜量化为正/负分，更适合作为风险标记）

### 2.5 新的指标 6 定义

```
指标 6: 结构性资金事件

性质: 混合指标
  ├── 层 1 (量化): 有方向性的事件加总为有向值 → 参与 CBS Score
  └── 层 2 (事件流): 完整事件明细 → Dashboard + 异动推送

层 1 回答的问题: "除了链上买卖之外，还有哪些结构性动向在暗示方向？"
层 2 回答的问题: "今天有哪些值得分析师关注的具体事件？"
```

### 2.6 与其他指标的重叠问题如何解决

**层 1 的数据来源与指标 1/4 完全不重叠**（通过以下规则保证）：

| 事件 | 指标 1 是否计入 | 指标 4 是否计入 | 指标 6 层 1 是否计入 |
|------|:--:|:--:|:--:|
| DEX Swap 买入 | ✓ | ✗ | ✗ |
| CEX 入金/出金 | ✗ | ✓ (金额) | ✓ (实体维度的方向性评分) |
| 跨链迁移 | ✗ | ✗ | ✓ |
| 冷→热转移 | ✗ | ✗ | ✓ |
| 做市商区间/库存变化 | ✗ | ✗ | ✓ |
| 做市商新增/撤出做市 | ✗ | ✗ | ✓ |
| 做市商自营 Swap | ✓ | ✗ | ✗ |
| 多做市商同向模式 | ✗ | ✗ | ✓ |
| 首次参与(买入) | ✓ (金额) | ✗ | ✗ (已计入指标 1) |

**关键规则：指标 6 层 1 只量化"其他指标算不了的方向性信号"。**

- CEX 入出金：指标 4 记录的是金额流向，指标 6 评估的是"谁在做"带来的方向性加权。两者数据源相同但分析维度不同——指标 4 说"CEX 净流出 $5M"，指标 6 说"这 $5M 中 $4M 来自 A1 类机构（偏空信号强）vs 来自 1000 个散户（偏空信号弱）"
- 做市商行为：指标 7 可能感受到流动性变化，但指标 6 层 1 捕捉的是做市商主动行为的方向性判断，两者互补不重叠

### 2.7 修正后的权重分配

```
w1 (净流入)      = 0.25
w2 (增持天数)    = 0.15
w3 (参与动态)    = 0.15
```
